# Harness Engineering Practices

Designing and using software engineering harnesses effectively.

This repository explores general principles for building and operating agent harnesses: goal decomposition, tool and skill design, evaluation, evidence, governance, and iterative improvement. It is not tied to a particular agent framework, employer, or technology stack.

The architecture and design notebook is in [docs/design-notebook.md](docs/design-notebook.md). It preserves the documented decisions and rationale while using generalized examples and release guidance.
